Structure Why?:

- src/ : keeps all .c files (your logic/implementation).
- include/ : keeps all .h header files (your interfaces).
Think of headers as contracts — they define what exists but not how it’s done.
- docs/ : is for clarity: you’ll be graded partly on explanation.
- snapshots/ : is for storing your “versions” — a simple simulation of Git’s object store.
- Makefile : automates builds. Instead of typing a long gcc command, make tracks changes and rebuilds only what’s modified.

In Mini-VCS we have multiple logical components:
- Commit management
- Repository management
- Hash computation
- File snapshot handling

|| Modular design prevents circular dependencies and makes debugging simpler (software architecture)
